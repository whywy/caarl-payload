Simulation & replay runs on this computer · same detector code as the payload

Desk simulation

Six made-up flights with sensor noise: normal, soft opening, late opening, chute failure, a bump on the pad, and extra noise. Each one is checked against what the detector must (and must not) do.

Replay a log with other settings

Runs a recorded flight (or a simulated one) through the detector with the settings below, and lists where each phase would change next to what the payload actually recorded. Logs from the card appear here once you've opened them above.
